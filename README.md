# 🐍 Python Learning Project

Welcome to the **Python Learning Project** repository! This repository contains a structured collection of Python scripts, practice exercises, and modules designed to build and reinforce core Python programming concepts.

---

## 📁 Repository Structure

Below is an overview of the key topics and module directories included in this project:

* **`basics/`** — Python fundamentals, variables, basic data types, and operators.
* **`control_statement/`** — Conditional branching (`if`, `elif`, `else`), loop controls (`for`, `while`), and break/continue flow.
* **`data_structures/`** — Core data collections including Lists, Tuples, Dictionaries, and Sets.
* **`functions/`** — Modular code concepts, functions, parameters, return values, and variable scopes.
* **`file_handling/`** — File reading, writing, appending, and context managers.
* **`exercises/`** — Hands-on algorithmic problems and practice challenges.

---

## ⚙️ Prerequisites

Ensure you have Python 3 installed on your system. You can check your current installation using:

```bash
python --version
# or
python3 --version
```

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/pankajrockz/PythonLearningProject.git](https://github.com/pankajrockz/PythonLearningProject.git)
   ```
2. **Navigate into the project directory:**
    ```bash
   cd PythonLearningProject
   ```
3. **Run a script:**
    ```bash
   python control_statement/<script_name>.py
   ```

## 📝 Learning Objectives
* Understand core Python syntax and execution logic.
* Practice structured problem-solving through clean, organized code snippets.
* Master essential data structures and control flow patterns.
